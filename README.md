# ProductivityTools.Fitness.Catalog.Web

Panel webowy (Angular 21) do przeglądania, dodawania i edycji ćwiczeń oraz animacji GIF w **ProductivityTools.Fitness.Catalog.Api**.

## Uruchomienie lokalne

```bash
npm install
npm start
```

* `npm start` uruchamia serwer deweloperski na `http://localhost:4201` i łączy się z `http://localhost:8085/api`.
* `npm run build` kompiluje wersję produkcyjną skierowaną na `https://fitness-catalog-api.productivitytools.top/api`.
* `npm test` uruchamia testy jednostkowe (Vitest).
